# Industry Catchment Tools

ArcPy scripts for summarising industrial nutrient loads by WFD catchment.

## Scripts

### industry_catchment_summary.py

Creates a summary table of industrial nutrient loads by catchment.

### Inputs

- IED_Loads_SLAMv4
- vector.SDE.WFD_Catchments_Cycle2

### Outputs

Table containing:

- CatchmentID
- Name
- SUM_N
- SUM_P
